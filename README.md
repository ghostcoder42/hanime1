# HAnime1

A mobile client for **hanimeone.me** — browse, watch, and download videos.

## Features

- **Browse** — genres, search, and an advanced filter sheet (sort / tags).
- **Watch** — in-app player with quality switching (480 / 720 / 1080p), download for offline viewing.
- **Library** — swipe between **Downloads · Favorites · History**.
- **Privacy** — *Hide Preview* blanks the app in the recents/app-switcher and blocks screenshots.
- **Languages** — English · 简体中文 · 繁體中文 · 日本語 · 한국어.
- **Dark mode**, and a switchable source domain (`hanimeone.me` ↔ `hanime1.me`) in Settings.

## Download

Pre-built packages are on the [**Releases**](../../releases) page.

### Android

Download the `.apk` and install it. (Enable **"Install unknown apps"** for your browser/files app if prompted.)

### iOS

The `.ipa` is **unsigned** — install it with [AltStore](https://altstore.io) or Sideloadly using **your own free Apple ID** (apps signed this way expire after 7 days and need re-signing).

## Source

All content comes from **https://hanimeone.me** (backup mirror **https://hanime1.me**, switchable in Settings). This app only reads the site; it is not affiliated with it.
